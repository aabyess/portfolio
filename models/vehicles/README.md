# 탈것 모델 (vehicles)

Blender에서 직접 만든 탈것입니다. 각진 로우폴리였던 1차 버전을 **사실적인 형태로 다시 만들었습니다**
(둥근 몸통·베벨 모서리·스무스 셰이딩, 나뭇결/등나무 텍스처, 가죽·철·크롬 재질). 원본은 `models/src/<이름>.blend`.

공통 규칙 (차와 동일, 1차 버전과도 동일)

- 앞쪽 = Blender **-Y** = glTF **+Z**, 위 = +Y(glTF)
- 원점 = 바닥 높이, 차체 중앙. 단위는 실제 미터
- 바퀴 오브젝트는 **원점이 바퀴 중심**, 회전 없음, 굴림 축 = 로컬 **X**
- 빈 오브젝트(Empty) **`seat`** = 탄 사람의 엉덩이 위치
- **Draco 압축**입니다. 차 로더처럼 `new GLTFLoader()`만 쓰면 못 읽습니다.
  월드 로더처럼 `loader.setDRACOLoader(draco)`를 꼭 붙이세요.
- 씬에 환경맵이 없어서 금속(크롬·철) 재질은 metalness 0.45~0.55 정도로만 줬습니다 (1이면 까맣게 나옴).

## horse.glb — 말타기

밤색(bay) 말 — 검은 갈기·꼬리, 무릎 아래 검은 다리, 이마의 흰 줄(블레이즈).
해부학적 몸통(가슴·배·엉덩이·관절·발굽)을 매끈한 한 덩어리로 만들고 **부드러운 스킨 웨이트**로 리깅했습니다.
마구: 모양 잡힌 안장(앞·뒤 턱), 안장 깔개(금색 테두리), 등자·등자끈, 뱃대끈, 뒤에 말아 묶은 담요, 굴레·재갈·고삐.
털색은 정점 색(COLOR_0)이라 `Horse_Coat` 재질은 `vertexColors`가 켜진 상태로 로드됩니다(GLTFLoader 자동).

- 메시: SkinnedMesh `horse` 1개 + 아마추어 `horse_rig`
- 뼈: `root` › `body` › `neck` › `head`, `tail` › **`tail_end`(새로 추가)**, 다리 `leg_{fl,fr,rl,rr}_{up,low}`
  — 기존 이름은 그대로이고 꼬리 끝 뼈만 하나 늘었습니다.
- 애니메이션(24fps, 루프, 제자리 — 루트 모션 없음, 길이 동일)
  - `Idle` 2.0 s · `Walk` 1.2 s · `Gallop` 0.58 s
- `seat` 는 `body` 뼈의 자식 → 걸음에 맞춰 같이 들썩입니다. (휴지 자세 위치 y=1.60)

## carriage.glb — 마차

말 한 마리(위와 같은 리그, 안장 대신 **목사리·등패드·배띠·봇줄·눈가리개 굴레**) + 덮개 달린 나무 짐마차.
모서리를 깎은 판자(나뭇결 텍스처 1장, 256px), 철띠 두른 바퀴통·살·테, 판스프링, 하중판(5륜),
늘어진 캔버스 덮개(뒤쪽은 끈으로 오므림), 쿠션 깔린 마부석·등받이, 발판, 브레이크 레버, 랜턴,
짐칸의 통·상자·자루, 뒤에 매단 양동이.

- 바퀴: `wheel_fl` `wheel_fr` (반지름 0.48) / `wheel_rl` `wheel_rr` (반지름 0.64) — 차와 같은 이름이라 그대로 굴러갑니다
- 차체: `carriage_body` (고정)
- 애니메이션 `Idle` `Walk` `Gallop` — 말만 움직입니다. 봇줄 뒤끝과 고삐의 마부 쪽 끝은 `root`에 묶여 마차에 붙어 있습니다
- `seat` = 마부석 (높이 1.51 m), 정적
- 랜턴 유리 재질 이름은 그대로 `Lantern_Glow` (vehicles.js가 이 이름으로 불빛 위치를 찾음)

## motorcycle.glb — 오토바이

1930년대풍 빈티지 바이크. 둥근 탱크(금색 줄), 스프링 달린 가죽 안장, 관 프레임, 와이어 스포크 바퀴,
깊은 흙받이, 냉각핀 달린 단기통 엔진, 피시테일 머플러, 스프링어 포크, 헤드램프, 짐받이·새들백.

- `wheel_front`, `wheel_rear` (반지름 0.33)
- `steer` = 핸들·포크·헤드램프·앞 흙받이. 원점이 조향축 위(높이 0.95), 수직축(glTF Y)으로 돌리면 됩니다
- **`wheel_front`는 `steer`의 자식** → 핸들만 돌리면 앞바퀴도 같이 꺾입니다. 굴림은 `wheel_front.rotation.x`
- `seat` 높이 1.065 m
- 헤드램프 유리 재질 이름은 그대로 `Lamp_Glass`

## bicycle.glb — 자전거

옛날식 숙녀용 자전거, 짙은 초록 프레임. 가는 관 프레임, 32살 와이어 바퀴, 가는 타이어,
스프링 가죽 안장, 뒤로 휜 핸들, 등나무 바구니(빵·사과), 체인·체인커버, 짐받이, 벨, 램프.

- `wheel_front`, `wheel_rear` (반지름 0.35), `wheel_front`는 `steer`의 자식
- `steer` = 핸들·포크·바구니·램프·앞 흙받이 (원점 = 조향축, 높이 0.84)
- `pedals` = 크랭크·체인링·페달. 원점이 크랭크 축, 로컬 X로 돌리면 됩니다 (체인링은 이제 오른쪽 = -X 쪽)
- `seat` 높이 1.04 m
- 램프 유리 재질 이름은 그대로 `Lamp_Glass`

## 코드에 붙일 때 참고

- 오브젝트·뼈·액션 이름과 바퀴 반지름, 원점, 조향축 위치는 1차 버전과 같습니다. 코드 수정 없이 파일만 바꿔도 됩니다.
- 차 로더는 `CAR_LEN / size.z` 로 크기를 맞춥니다. 이 파일들은 실제 미터라
  탈것마다 `CAR_LEN` 대신 길이를 따로 주거나 `scale = 1`로 두는 편이 자연스럽습니다.
- 오토바이·자전거 바퀴 이름은 `WHEEL_SPEC`에 없습니다 (`wheel_front` / `wheel_rear`).
- 말 액션은 `AnimationMixer`로 `Idle/Walk/Gallop`을 이름 그대로 찾으면 됩니다.
