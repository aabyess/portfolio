# 선술집 소품 (props)

프로젝트 스테이션의 포장마차 손수레와 빨간 플라스틱 의자·테이블을 바꾸는 **중세 선술집 부스 7종 + 좌석**입니다.
탈것과 같은 화풍(베벨 모서리, 나뭇결·회벽·돌·이엉·기와 텍스처 256px, 철·구리 재질)이고 모두 **Draco 압축**입니다
(`loader.setDRACOLoader(draco)` 필요). 원본은 `models/src/<파일이름>.blend`.

공통 규칙: 앞쪽 = glTF **+Z** (Blender -Y), 위 = +Y, 원점 = 바닥 중앙. 카메라·조명 없음.

## 부스 7종 — `tavern-<style>.glb`

**단위 주의: 부스 파일은 스테이션 그룹 단위**입니다 (실제 미터 ÷ 0.62).
지금 손수레가 들어 있는 그룹 `g`(`g.scale.setScalar(0.62)`, `g.rotation.y` = 길 쪽)에
**위치 (0,0,0), 회전 0, 스케일 1** 그대로 넣으면 손수레 자리에 정확히 맞습니다. 앞(+Z)이 길을 봅니다.

```js
const booth = gltf.scene;            // tavern-tudor.glb 등
g.add(booth);                        // position/rotation/scale 그대로
booth.traverse(o => { if (o.isMesh) { o.castShadow = o.receiveShadow = true; } });
```

손수레 코드(몸통·바퀴·기둥·줄무늬 차양·전구 줄·상판 상자)와 "선술집 꾸밈" 블록(빨간 등롱, 酒 깃발, 막걸리 항아리, 술병·사발)은
부스에 같은 역할의 소품이 다 들어 있으니 지우면 됩니다. 바닥 색 원(ring), 간판(face: 액자·화면·라벨), 따뜻한 PointLight는 그대로 둡니다.

### 부스 공통 부품

- **`sign_face`** — 이름판 앞면만 따로 뗀 사각형 메시(재질 `Sign_Face`, UV 0~1, +Z를 봄).
  프로젝트 이름을 캔버스에 그려 `sign_face.material.map` 에 넣으면 됩니다. 빈 나무판 그대로 둬도 어색하지 않습니다.
- **불빛 재질** — `Lantern_Glow`(랜턴 유리), `Flame_Glow`(횃불·화로 불꽃), `Firebox_Glow`(플랑드르 솥 아궁이). 모두 emissive.
  밤 조명(nightGlow)에 넣으려면 `o.material.name` 으로 찾아 emissiveIntensity 를 조절하세요.
- **크기 제한** — 바닥에 닿는 것은 모두 실제 x ±2.6 m, 앞 y ≥ -1.4 m(테이블 쪽 의자와 안 겹침), 뒤는 간판 기둥(그룹 z = -2.8) 앞에서 끝납니다.
  다만 지붕 꼭대기가 지금 간판 아래 끝(그룹 y 4.75)보다 높은 부스가 있어서(위 표 '그룹 단위 꼭대기'),
  정면 낮은 시점에서는 간판 아래쪽이 지붕에 조금 가립니다. 필요하면 `face.position.y = Math.max(0, 꼭대기 - 4.6)` 정도 올려 주세요.

물리 몸체(CANNON.Cylinder)는 지금 그대로 둡니다. 다만 **지금 코드는 메시 원점을 몸체 중심(높이의 절반)에 둡니다**.
GLB 원점은 바닥이라, 빈 그룹으로 한 번 감싸 아래로 내려 주세요:

```js
const holder = new THREE.Group();
const m = stoolGltf.scene.clone(); m.position.y = -0.42 / 2;   // 테이블이면 -0.7 / 2
holder.add(m);
place(holder, new CANNON.Cylinder(0.2, 0.17, 0.42, 10), x, z, 0.42, 0.35);
```

의자 높이·위치(테이블 지역좌표 (0, 4.6), 반지름 1.75)가 그대로라 `npcs.js` 의 `STOOL_*` 상수는 바꿀 필요가 없습니다.
부스별 추천 좌석: tudor → stool·bench, bavarian → bierbank·stool, norse → log, osteria → chair,
venta → stool, flemish → barrel, tent → crate·barrel. 물리 몸체는 의자류 모두 지금의 원통(반지름 0.2, 높이 0.42) 그대로 쓰면 되고,
벤치는 길어서 원통 대신 `CANNON.Box(0.6, 0.21, 0.15)` 정도가 맞습니다.

## 디테일 메모

- 부스 둘레 바닥에 풀 덤불이 조금 들어 있습니다. 포도 덩굴·덤불·꽃·풀은 가벼운 양면 잎 카드입니다.
- 벽돌·회벽·돌은 월드 기준 UV라 늘어나지 않고, 나무는 결 방향 UV입니다. 텍스처는 256px JPEG를 부스 안에 넣었습니다.
