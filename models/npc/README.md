## 공통 규격

- **Draco 압축**: `GLTFLoader.setDRACOLoader(draco)`가 필요합니다. 월드 로더의 `DRACOLoader`를 같이 쓰면 됩니다.
- **방향과 원점**: 앞은 glTF 기준 +Z입니다(`person.glb`와 같음). 원점은 발 중앙입니다.
- **키**: 약 1.8 m입니다. 음유시인은 깃털 때문에 1.92 m입니다.
  - 바운딩박스로 자동 스케일하면 모자 쓴 캐릭터가 조금 작아집니다. 고정 배율(예: `1.95 / 1.8`)을 권장합니다.
- **재질**: 기본 색상만 씁니다. 텍스처는 없고 양면(double-sided)입니다.
- **복제**: 여러 명을 놓을 때는 스킨드 메시이므로 `SkeletonUtils.clone`으로 복제하세요.

## 애니메이션 (24 fps, 모두 반복 재생)

| 클립 | 길이 | 내용 |
|---|---|---|
| `Idle` | 3초 | 서서 숨쉬기 |
| `Walk` | 1초 | 제자리 걷기입니다. 루트 모션이 없으니 이동은 코드에서 처리합니다 |
| `Sit` | 4초 | 의자에 앉아 흔들흔들 |
| `Drink` | 3초 | 앉아서 잔을 입으로 가져가 마심 |
| `Cheers` | 1.5초 | 앉아서 잔을 앞으로 들어 건배 |

## 뼈대 (18개, 10종 모두 같음)

`Hips`(루트), `Spine`, `Chest`, `Neck`, `Head`, `UpperArm.L/R`, `LowerArm.L/R`, `Hand.L/R`,
`UpperLeg.L/R`, `LowerLeg.L/R`, `Foot.L/R`, `Prop.R`(오른손 잔)

- **나무 잔**: 잔은 `Prop.R`에 붙어 있습니다.
  - `Idle`과 `Walk`에서는 이 뼈의 스케일이 0.001이라 잔이 숨겨집니다.
  - `Sit`, `Drink`, `Cheers`에서는 스케일이 1이라 보입니다.
  - 다른 소품은 `Hand.R`이나 `Prop.R`에 `Object3D`를 붙이면 됩니다.
- **약초꾼 바구니**: `UpperArm.L`에 붙어 있어서 앉아도 거의 똑바로 섭니다.

## 의자(앉기) 기준 (모델 단위 1.8 m 기준)

- **의자**: 상판 높이 0.42 m이고, 캐릭터 원점 바로 아래(XY 중앙)에 둡니다.
  - NPC를 의자 바닥 위치에 놓고, 의자 반대쪽을 바라보게 돌리면 됩니다.
- **앉은 자세**: `Hips`가 0.42 내려갑니다(골반 관절 높이 약 0.50). 허벅지는 수평, 정강이는 수직, 발은 바닥에 닿습니다.
- **필요한 앞 공간**: 무릎이 앞으로 약 0.42 m, 발끝이 약 0.57 m까지 나옵니다.
- **잔 위치**:
  - `Sit`: 오른쪽 허벅지 위(높이 약 0.69)
  - `Drink`(40프레임): 입 높이(약 1.24)
  - `Cheers`(14프레임): 앞쪽 높이 약 1.17
