# 차 모델 교체하기

`f-drive.html`은 이 폴더의 **`car.glb`** 를 자동으로 불러옵니다.
파일이 없으면 박스로 만든 기본 차가 그대로 쓰입니다. (에러 안 납니다)

Blender에서 차를 만들고 `car.glb`로 내보내면 그대로 교체됩니다.

## Blender 내보내기 설정

`File > Export > glTF 2.0 (.glb/.gltf)`

| 항목 | 값 |
|---|---|
| Format | **glTF Binary (.glb)** |
| Include | Selected Objects 체크 (차만 내보낼 때) |
| Transform → +Y Up | **체크** (기본값) |
| Data → Mesh → Apply Modifiers | 체크 |
| Data → Material | Export |

## 지켜야 할 것 두 가지

### 1. 차가 -Z 방향을 보게 만들기

Blender 뷰포트에서 **차 앞코가 -Y 축을 향하게** 두고 내보내세요.
(glTF로 나가면서 Blender의 -Y가 three.js의 -Z가 됩니다)

앞이 반대로 나오면 차가 뒤로 달리는 것처럼 보입니다.

### 2. 바퀴 오브젝트 이름

바퀴를 따로 분리하고 이름을 정확히 이렇게 지으면 **조향과 굴러가는 회전이 자동으로 붙습니다.**

```
wheel_fl   왼쪽 앞
wheel_fr   오른쪽 앞
wheel_rl   왼쪽 뒤
wheel_rr   오른쪽 뒤
```

- 각 바퀴의 **오브젝트 원점(Origin)을 바퀴 한가운데**에 두세요.
  (`Object > Set Origin > Origin to Geometry`)
  원점이 엉뚱한 데 있으면 바퀴가 궤도를 그리며 돕니다.
- 이름이 다르거나 바퀴를 합쳐서 내보내면 차체만 움직입니다. 그래도 주행은 정상입니다.

## 크기는 안 맞춰도 됩니다

코드가 불러올 때 **차 길이를 기준으로 자동으로 크기를 맞추고**, 좌우·앞뒤 중심을 잡고,
바퀴가 바닥에 닿도록 높이를 내립니다. Blender에서 몇 미터로 만들든 상관없습니다.

바꾸고 싶으면 `f-drive.html`의 `CAR_LEN` 값을 조정하세요 (기본 4.2).

## 용량

포트폴리오는 처음 열리는 속도가 중요합니다. **2MB 이하**를 권합니다.

- 텍스처는 1024×1024 이하, JPG/WebP
- 폴리곤은 수만 개까지 갈 필요 없습니다. 지금 월드가 로우폴리 스타일이라
  각지고 단순한 쪽이 오히려 잘 어울립니다
- 용량이 크면 [gltf-transform](https://gltf-transform.dev/) 으로 압축할 수 있습니다

## 차 말고 다른 것도

같은 방식으로 나무·바위·게시판도 모델로 교체할 수 있습니다.
지금은 코드에서 원뿔·상자로 만들고 있어서, 필요하면 말씀해 주세요.
