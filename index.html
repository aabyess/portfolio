    • 
            
  • Supabase RLS + 서비스롤 API 이중 권한 구조 설계 — RLS로 행 접근을 통제하고, RLS를 우회하는 서비스롤 라우트엔 소유권·상태 전이 화이트리스트 검증을 직접 구현(완료 계약 되돌리기, 마감 공고 견적 제출 등 차단)
    • 
            
  • Gemini 구조화 출력(responseSchema)으로 공고·견적 AI 초안을 생성하고, 발주서 PDF·이미지를 멀티모달로 추출, 모델 과부하(503) 시 폴백 체인으로 무중단 처리
    • 
            
  • 간헐적 강제 로그아웃의 원인이 미들웨어의 리다이렉트 쿠키 누락이라는 것을 프론트·백엔드를 함께 추적해 발견, 모든 리다이렉트에 쿠키를 전파하는 헬퍼로 재발 방지
    • 
            
  • 채팅 읽음 처리가 행마다 UPDATE 이벤트를 발생시켜 전체 이력 refetch가 폭주하던 문제를 Realtime 페이로드를 setQueryData로 캐시에 직접 반영하도록 바꿔 해결
