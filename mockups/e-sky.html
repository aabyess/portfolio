Trade-Cmarket — 한국·인도네시아 B2B 무역 견적·계약 플랫폼

발주 공고부터 견적·낙찰·계약·실시간 채팅까지 거래 플로우 전체를 바이어·셀러 양면으로 혼자 기획·설계·구현했습니다.

  • Supabase RLS와 서비스롤 API로 이중 권한 구조를 설계해, RLS를 우회하는 경로에도 소유권·상태 전이 검증을 직접 붙였습니다. 완료된 계약 되돌리기, 마감 공고 견적 제출 같은 조작을 차단했습니다.
  • 3개 국어 서비스에서 번역본을 원문·감지언어와 함께 저장하고 생성은 서버로만 강제해, 클라이언트발 번역 위조를 막았습니다.
  • 간헐적 강제 로그아웃의 원인이 미들웨어의 리다이렉트 쿠키 누락임을 프론트와 백엔드를 함께 추적해 찾아내고, 헬퍼로 재발을 막았습니다.
  • 채팅 읽음 처리가 행마다 이벤트를 발생시켜 전체 이력을 다시 불러오던 문제를, 수신 페이로드를 캐시에 직접 반영하도록 바꿔 해결했습니다.
  • Gemini 구조화 출력으로 공고·견적 초안을 생성하고, 발주서 PDF·이미지를 멀티모달로 추출했습니다. 모델 과부하 시 폴백 체인으로 무중단 처리했습니다.
  • 전 API 라우트 보안 감사를 수행해 저장형 XSS 살균, 무인증 번역 프록시 차단, 업로드 MIME·용량 검증을 일괄 적용했습니다.

02 5인 팀 · 프론트엔드 전담 2026.05 — 2026.10
놀러온나 — 부산 특화 예산 맞춤 여행 플랫폼

한국관광공사 TourAPI 기반 여행 플랫폼에서 서비스 전 페이지의 프론트엔드를 혼자 설계·구현했습니다. (프론트 1, 백엔드 3, PM 1)

  • 장소 매핑 상한이 3,000개로 하드코딩돼 실데이터 3,632개 중 632개가 누락되던 버그를 발견했습니다. 상한을 올리고 37회 순차 요청을 8개 단위 병렬로 바꿔 초기 로딩도 함께 개선했습니다.
  • 부산 16개 구 혼잡도 지도를 Kakao Maps SDK로 구현하고, 원형 마커를 실제 행정구역 경계 폴리곤으로 교체해 구 클릭부터 상세 모달까지 이어지는 탐색 흐름을 설계했습니다.
  • AI가 생성한 코스를 사용자가 직접 다듬도록 순서 변경·제외·드래그 정렬·예산 게이지를 붙인 편집 흐름을 구현했습니다.
  • 카카오 SDK 스크립트 로드 전에 지도를 초기화해 발생하던 레이스 컨디션을, 스크립트 태그를 재확인한 뒤 load 이벤트를 붙이는 폴백으로 해결했습니다.
  • 모바일에서 카드 드래그가 목록 스크롤을 막던 문제를, 화면 크기를 감지해 데스크톱·모바일 드래그 방식을 분리하는 방식으로 해결했습니다.
  • 스팟 검색을 지역명·카테고리·무료 여부·초성까지 인식하는 통합 검색으로 확장하고, 결과에 맞춰 지도 범위가 자동 재조정되도록 했습니다.
