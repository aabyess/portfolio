# 디자인 시안

최종본은 루트의 `index.html`이며, 이 폴더는 버려진 시안 기록용입니다.

같은 콘텐츠로 방향을 비교할 수 있게 만든 시안입니다.
각 파일을 브라우저로 열면 바로 확인할 수 있습니다.

## 시안 F — 운전하는 3D 포트폴리오 (현재 방향)

`f-drive.html`

차를 몰고 돌아다니며 프로젝트를 보는 포트폴리오. bruno-simon.com과 같은 장르이고,
디자인·월드·코드는 전부 직접 만든 것입니다.

- 밝은 톤(하늘색 배경 + 모래색 바닥)이라 다크 시안의 눈부심 문제가 없습니다
- 프로젝트 6개가 각각 게시판으로 서 있고, 실제 스크린샷이 붙습니다 (놀러온나는 영상)
- 게시판 구역에 들어가면 상세 패널이 열리고, 좌하단 목록에 발견 표시가 채워집니다
- WASD·방향키 운전, 모바일은 화면 버튼
- 빌드 도구 없이 단일 HTML. Three.js를 CDN ES 모듈로 로드합니다

### 3D 포트폴리오의 약점과 대응

캔버스 안의 내용은 검색엔진과 스크린리더에 보이지 않고, 폰으로 보는 사람도 있습니다.
그래서 정문은 3D로 두되 읽기용 경로를 항상 열어둡니다.

- 우상단에 **읽기용으로 보기** 버튼 — `e-sky.html`로 이동
- 페이지 안에 프로젝트 전문을 담은 숨김 텍스트(`.sr`)를 둬서 크롤러·스크린리더가 읽음
- WebGL을 못 쓰는 환경이면 읽기용 페이지로 안내하는 화면을 자동 표시

### 검증한 것

브라우저에서 실제로 돌려 확인했습니다.

- 6개 스테이션 각각 올바른 패널이 열리고 카운터가 1→6으로 증가
- 전속력으로 통과해도 패널이 유지됨 (자동으로 닫으면 1초도 안 돼 사라짐)
- × 로 닫으면 같은 구역에 머무는 동안 다시 열리지 않고, 벗어났다 돌아오면 다시 열림
- 콘솔 에러·경고 없음

`?test=1`을 붙이면 `window.__drive`로 주행 로직을 프레임 루프 없이 실행할 수 있습니다.
(백그라운드 탭에서는 브라우저가 `requestAnimationFrame`을 멈추기 때문에 필요했습니다.)

### 아직 안 된 것

- **모바일 실기기 테스트** — 터치 버튼은 붙였지만 실제 기기에서 확인하지 않았습니다.
  저사양 기기 성능도 미검증입니다.
- **취미 게임 구역** — 게임 정보를 받으면 별도 구역으로 추가할 수 있습니다.
- **이력서 PDF** 링크

## 읽기용 시안 (F의 대체 경로이자 단독으로도 사용 가능)

`d-interview.html` (딥그린) 과 `e-sky.html` (하늘색) — **구조는 동일하고 색만 다릅니다.**

면접관이 짧은 시간에 훑는 상황에 맞춘 구성입니다.

- 첫 화면에서 이름·역할·한 줄 요약·주력 스택·프로젝트 수·이력서/GitHub/이메일이 모두 보임
- 기술 요약 섹션 (Frontend / Backend·Data / 연동 / 테스트), 주도 경험 기술은 강조 표시
- 프로젝트는 핵심 성과 3개만 노출하고 나머지는 "더 보기" 토글
- 인쇄 스타일 포함 — PDF로 출력하면 헤더·버튼이 빠지고 접힌 불릿이 모두 펼쳐짐

하늘색은 흰 배경에서 대비가 떨어져, `e-sky.html`은 텍스트·버튼에 sky-700
(`#0369a1`, 흰 배경 대비 5.9:1)을 쓰고 분위기는 옅은 하늘빛 배경·테두리로 냈습니다.

## 초기 시안 (보류)

| 파일 | 방향 | 피드백 |
|---|---|---|
| `a-editor.html` | 코드 에디터 — 탭 바, YAML 프론트매터, JSON 연락처 | 정신없음 |
| `b-tui.html` | 터미널 TUI — 사이드바 파일트리, ASCII 아트, 스캔라인 | 정신없음 |
| `c-neon.html` | 네온/게임 — 그라디언트 메시, 글래스 카드 | 정신없음 |
| `d-interview.html` / `e-sky.html` | 밝고 차분한 정보 중심 | 밋밋함 |

다크 계열 세 개는 채도 높은 강조색과 스캔라인·글로우를 동시에 써서 산만했고,
밝은 두 개는 반대로 요소를 너무 덜어내 밋밋했습니다. 시안 F는 밝기는 유지하면서
콘텐츠 자체를 입체적으로 만드는 방향입니다.

## 모든 시안의 공통 수정 사항

- Pretendard를 jsDelivr에서 로드. 기존 `index.html`은 Google Fonts에서
  요청하는데 Google Fonts는 Pretendard를 호스팅하지 않아 실제로는
  시스템 폰트로 폴백되고 있습니다.
- Trade-Cmarket(1인 풀스택)을 첫 프로젝트로 배치
- 모바일 내비게이션 실종 문제 해결
- `prefers-reduced-motion` 대응, `:focus-visible` 포커스 링
