# 디자인 시안

같은 콘텐츠로 방향을 비교할 수 있게 만든 시안입니다.
각 파일을 브라우저로 열면 바로 확인할 수 있습니다.

## 면접관 우선 구조 (현재 방향)

`d-interview.html` (딥그린) 과 `e-sky.html` (하늘색) — **구조는 동일하고 색만 다릅니다.**

밝고 차분한 바탕, 강조색 하나, 넉넉한 여백. 개성을 테마가 아니라
정보 구조와 타이포 위계에서 만듭니다.

- 첫 화면에서 이름·역할·한 줄 요약·주력 스택·프로젝트 수·이력서/GitHub/이메일이 모두 보임
- **기술 요약 섹션** (Frontend / Backend·Data / 연동 / 테스트), 주도 경험 기술은 강조 표시
- 프로젝트는 핵심 성과 3개만 노출하고 나머지는 "더 보기" 토글
- 대표 2개는 스크린샷과 함께 크게, 나머지 4개는 컴팩트 카드
- 취미(Playground)는 맨 아래로 분리
- 인쇄 스타일 포함 — PDF로 출력하면 헤더·버튼이 빠지고 접힌 불릿이 모두 펼쳐짐

### 색상 대비

하늘색은 흰 배경에서 대비가 떨어지기 쉬워, `e-sky.html`은 텍스트·버튼에
sky-700(`#0369a1`, 흰 배경 대비 5.9:1)을 쓰고 분위기는 옅은 하늘빛
배경·테두리·히어로 워시로 냈습니다.

작은 메타 라벨에 쓰던 `--subtle`이 두 시안 모두 약 3:1로 WCAG AA(4.5:1)에
미달해 각각 `#6e6c64`(5.3:1), `#64788a`(4.6:1)로 어둡게 조정했습니다.

## 초기 시안 (다크 계열 — 눈부심 이슈로 보류)

| 파일 | 방향 |
|---|---|
| `a-editor.html` | 코드 에디터 — 탭 바 내비게이션, YAML 프론트매터, JSON 연락처 |
| `b-tui.html` | 터미널 TUI — 사이드바 파일트리, ASCII 아트, 스캔라인 |
| `c-neon.html` | 네온/게임 — 그라디언트 메시, 글래스 카드 |

세 시안 모두 다크 바탕에 채도 높은 강조색을 써서 긴 한글 본문을
읽기 피로하게 만들었습니다. 면접관이 밝은 환경에서 짧은 시간에
훑는 상황과 맞지 않아 방향을 바꿨습니다.

## 모든 시안의 공통 수정 사항

- Pretendard를 jsDelivr에서 로드. 기존 `index.html`은 Google Fonts에서
  요청하는데 Google Fonts는 Pretendard를 호스팅하지 않아 실제로는
  시스템 폰트로 폴백되고 있습니다.
- Trade-Cmarket(1인 풀스택)을 첫 프로젝트로 배치
- 모바일 내비게이션 실종 문제 해결
- `prefers-reduced-motion` 대응, `:focus-visible` 포커스 링, 건너뛰기 링크

## 아직 채워야 할 것

- **이력서 PDF** — 헤더와 첫 화면의 버튼이 현재 `#`로 비어 있습니다.
- **취미 게임 정보** — Playground의 게임 카드는 실제 정보가 없어 임시 내용입니다.
  제목 / 장르 / 사용 엔진 / 스크린샷이 필요합니다.
